# Nickname fallback fonts

Bundled from [Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl), revision `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

- Noto Sans: extended Latin, Cyrillic and subscript characters.
- Noto Sans Math: styled mathematical letters.
- Noto Sans Symbols 2: decorative symbols.
- Noto Emoji: monochrome emoji.

Each font is redistributed under the accompanying SIL Open Font License 1.1. These fallbacks supplement the existing system CJK font.
